## Project description
This project demonstrates a beginner-friendly sales analytics workflow using Python, pandas, NumPy, and Matplotlib. It creates a synthetic sample dataset, checks data quality, calculates revenue KPIs, visualizes monthly/category/region performance, and prints example insights.

> **Important:** The dataset is synthetic and created by the notebook. It is not real company data. Replace it with an approved public or project dataset if your internship instructions require one, and cite the source.

## Files
- `JayRajput_SalesDataAnalysis.ipynb` — complete notebook and analysis.
- `requirements.txt` — Python dependencies.
- `JayRajput_ProjectReport.docx` — project report.
- `README.md` — this overview and run guide.

## Requirements
- Python 3.10 or newer recommended
- Jupyter Notebook or JupyterLab

## Setup and run
1. Download all four files into the same folder.
2. Open a terminal in that folder.
3. Create and activate a virtual environment (recommended).
4. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Start Jupyter:

   ```bash
   jupyter notebook
   ```

6. Open `JayRajput_SalesDataAnalysis.ipynb` and run the cells from top to bottom.

The notebook generates the sample data automatically. No external dataset download is required. Three CSV summary files are created when the final export cell runs.

## Main analyses
- Dataset inspection and basic cleaning
- Total revenue, units sold, average transaction revenue, and transaction count
- Monthly revenue trend
- Revenue by product category
- Revenue by region
- Automatically generated sample-data observations

## Limitations
Because the dataset is synthetic, results are illustrative only and should not be used for actual business decisions. The analysis describes patterns but does not establish causation or build a predictive machine-learning model.
